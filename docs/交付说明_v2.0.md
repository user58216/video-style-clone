## 二、v2.0 通用化改造清单

| 改造点 | 之前（v1.x） | 现在（v2.0） |
|---|---|---|
| 使用者 | 绑定单一产品 | 任何 AI Agent（Skill 触发/手册注入）+ 人类 CLI |
| 制作路线 | 仅纯程序化重绘 | A 纯程序化 / B 原片保留+自制段（混合） |
| 音效 | 无 | `make_sfx.py` 参数化合成（riser/ding/impact） |
| 部署文档 | 特定启动器专属 | 通用三要素原理+公式，多技术栈（Electron/Web/Unity/macOS） |
| 字体 | 仅 Windows 路径 | Windows/macOS/Linux fallback |
| 上手门槛 | 需读全部分镜代码 | `render_template.py` 开箱即跑 3 秒 demo |
| 平台工具依赖 | 内置平台工具调用 | 通用表述（按所在平台规范执行） |

## 四、三种使用方式

1. **支持 Agent Skills 的环境**（TeleAgent / Claude 等）：把仓库文件夹放入技能目录，说"效仿这个视频做一个同类型的动画"即可触发；
2. **其他 AI 助手（ChatGPT/Cursor/任意 LLM）**：把 SKILL.md 和需要的 references 粘贴进对话作为任务手册；
3. **人类直接用**：`python scripts/render_template.py` 先跑通 demo，再改 SCENES 表创作。

## 五、改进思路（详见 ROADMAP.md）

- 短期：CLI 化（pip 安装一条命令成片）、JSON 声明式分镜、GIF/竖屏预设、CI 跨平台冒烟测试
- 中期：风格模板库、节拍对齐音效、AI 生图抽象层、自动部署适配器
- 长期：社区分镜共建、英文完整版、实时预览

四条不变的设计原则：本地优先 / 确定性可复现 / 只学风格不搬素材 / 渐进披露。
