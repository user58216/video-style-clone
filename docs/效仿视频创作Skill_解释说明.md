# Skill《效仿视频创作》（video-style-clone）解释说明

> 本文面向使用者（也是比赛展示材料），解释这个 Skill 是什么、怎么用、技术原理和实战验证情况。
> Skill 本体已安装并启用（注册回执 `{"ok": true, "reason": "enabled"}`）。

---

## 一、一句话介绍

给我一段参考视频，我先"看懂"它的类型、风格、节奏和叙事结构，然后用代码逐帧绘制一条同类型的新视频——全程本地完成，还能直接部署为软件的启动画面。

## 二、基本信息

| 项目 | 内容 |
|---|---|
| 技能名称 | video-style-clone |
| 界面显示名 | 效仿视频创作 |
| 触发方式 | 提供视频路径 + 说"效仿这个视频 / 照着做一个同类型的 / 仿照这个风格做动画" |
| 进阶触发 | "把这条视频设为 TeleAgent 启动画面 / 启动动画" |
| 运行环境 | Windows + Python3（numpy/Pillow）+ ffmpeg，无需联网、无需上传素材 |
| 默认产物 | 1920×1080 / 30fps / H.264 MP4，输出到 `D:\TeleAgent输出\` |

## 三、它能做什么 / 不能做什么

**能做：**
- 复古点阵 / 线稿 / 几何风格的 MG 动画、概念广告
- 片头、启动动画、Logo 演绎、数据可视化动画
- 风格技法：点阵化、半调网点、线稿扫描绘制、AI 检测框+标签、数字雨、粒子汇聚、神经网络球、轨道环、打字机文字、黑白噪点转场等
- 一键部署为 DragonCodexBoot 类启动器的开机动画

**不做（边界）：**
- 真人实拍、复杂 3D 渲染、需要 After Effects 级别特效的镜头
- 剪辑混剪类（需要原素材参与的视频）
- 复制参考视频的版权画面/角色/品牌元素（红线：仅分析风格，不搬素材）

## 四、工作流程（六步 + 进阶）

```
参考视频 ──► ①素材解析 ──► ②需求确认 ──► ③分镜设计 ──► ④逐帧渲染
                                                          │
        成品MP4 ◄── ⑥交付（report+清理） ◄── ⑤合成+双重质检 ◄┘
                                                          │
                              （可选）⑦部署为启动动画 ◄────┘
```

1. **素材解析**：`scripts/analyze_reference.py` 一条龙完成 ffprobe 元数据读取、每秒 2 帧关键帧抽取、网格拼图；再由视觉模型从拼图读出叙事逻辑、逐格内容、风格关键词、节奏与转场。
2. **需求确认**：三个决策点一次问清——主题内容（换品牌/通用/自定义）、文案语言（原语言/中文/双语）、配乐（生成/无声）。
3. **分镜设计**：按参考片幕数与节奏排场景时间轴表；快切段每幕 0.8~1.2 秒，点题与结尾放缓；黑白反转、噪点闪切、白闪做转场。
4. **逐帧渲染**：场景时间轴驱动的场景函数（`fn(img, dr, tt, dur)`），固定随机种子保证帧间稳定；先出 15 帧抽样预览再全量渲染，避免返工。
5. **合成与双重质检**：ffmpeg 合成 H.264；渲染前抽帧拼图预检一次，成品再抽 40 帧终检一次，逐格核对无黑场、无缺失。
6. **交付**：输出到偏好目录，上报文件卡片，清理中间帧。

**进阶（启动动画部署）**：把 MP4 部署到启动器 `media/startup.mp4`，按视频总时长 T 换算衔接参数（`HoldAt≈T-3`、`TransitionStart≈T-1.3`、`TransitionEnd≈T-0.3`，ScreenFrames 矩形轨迹对准结尾主体图形），运行 `--self-test` 无界面自检（不弹窗不打扰当前会话），接管快捷方式但保留官方图标，改配置前先备份。

## 五、技术原理（为什么用代码逐帧渲染）

传统做法是"剪辑参考素材"或"套 AE 模板"，前者有版权风险、后者依赖专业软件。本 Skill 选择**纯程序化绘制**：

- **风格即算法**：点阵=剪影网格采样；半调网点=密度随明暗衰减的随机点；扫描线=按 y 裁剪的线段显隐；AI 检测框=比例坐标矩形+四角 L 线+打字机标签；粒子=（起点→目标节点）插值+缓动函数；神经网络球=斐波那契球面布点+绕轴旋转投影+近邻连线。
- **确定性**：所有随机数固定种子，任意帧可复现、可单独重渲。
- **渐进披露**：SKILL.md 只放工作流（触发后加载约 200 行），渲染细节和部署细节分别放在 `references/rendering.md`、`references/boot-deploy.md`，用哪步读哪步，不浪费上下文。
- **可复用脚本**：素材解析做成 `scripts/analyze_reference.py`，一条命令完成"元数据+抽帧+拼图"，已实测通过。

## 六、实战验证记录（本 Skill 的诞生过程）

| 轮次 | 任务 | 结果 |
|---|---|---|
| 第 1 轮 | 效仿 17s 黑白点阵 AI 概念广告，制作 v1（16 幕，含点题句、AI 球、粒子生成） | 17.5s 成品，逐段终检无缺失，部署为启动动画并自检通过 |
| 第 2 轮 | 升级科幻感与 AI 味：加入六大世界地标（金字塔/自由女神/埃菲尔铁塔/大本钟/上海外滩/哈利法塔）的"AI 视觉识别"蒙太奇，以及数据洪流、神经网络生长、轨道环终章 | 20s 成品（10 场景），40 帧终检通过，已替换为启动画面 |
| 第 3 轮 | 将全过程沉淀为 Skill：验证（结构 valid）→ 安全扫描（0 风险）→ 注册（enabled） | 技能"效仿视频创作"已启用，随时可触发 |

两次实战还沉淀了完整分镜实录（见 `references/rendering.md` 第五节），下次同类任务可直接对照复用。

## 七、在比赛中的用法建议

1. **现场演示**：直接说"效仿这条视频做一个同类型的"，展示"参考片→分析→确认→成片"的全自动过程；
2. **强调本地化**：素材不上传、全程本机渲染，数据安全是卖点；
3. **强调沉淀**：同一主题的迭代（v1→v2）只需改分镜参数，技法库可复用，体现"Skill 越用越强"；
4. **红线加分**：主动说明"只学风格不搬素材"的版权策略，呼应比赛"数据必须真实"的要求。

## 八、迭代方向（Skill 还能怎么长大）

- 接入配乐生成（numpy 合成器音序），补齐"有声版"能力；
- 技法库继续扩充：粒子文字、3D 星空、屏幕 glitch 等风格模板；
- 支持用户自定义品牌色/图标资产（assets 目录）；
- 启动动画支持多套视频轮换（配置多 ScreenFrames 预设）。
