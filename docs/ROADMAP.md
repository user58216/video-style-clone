# ROADMAP · 路线图与改进思路

欢迎按此路线图提 Issue / PR。

## v2.0（已完成）

- [x] 通用化：去除平台绑定，任何 AI Agent / 软件可复用
- [x] 双制作路线：A 纯程序化重绘 / B 原片保留+自制段
- [x] 混合模式文档（图标特征提取 → AI 生图 → 程序叠加 → 拼接）
- [x] 程序化音效（make_sfx.py + 配方文档）
- [x] 跨平台字体 fallback 与终端差异说明
- [x] 开箱 demo（render_template.py）

## 短期（v2.x）

- [ ] **CLI 化**：`pip install video-style-clone` 后 `vsc render --config storyboard.json` 一条命令成片
- [ ] **JSON 分镜格式**：分镜表从代码里抽出来变成声明式配置，非程序员也能改
- [ ] **GIF/WebM 输出**：社交平台尺寸预设（竖屏 9:16、方形 1:1）
- [ ] **Web 预览器**：本地静态页快速浏览帧序列，替代抽帧拼图人工检查
- [ ] **CI 冒烟测试**：GitHub Actions 自动跑 render_template.py 验证跨平台

## 中期（v3）

- [ ] **风格模板库**：赛博朋克 / 水墨 / 像素 / 杂志排版等可插拔风格包
- [ ] **音效增强**：节拍对齐（BPM 检测让转场落在鼓点上）、更多合成器音色
- [ ] **AI 生图抽象层**：可插拔图像生成后端（本地 SD / 云端 API），prompt 模板化管理
- [ ] **自动部署适配器**：Electron/Tauri/Unity 启动页生成器，从"文档指导"变成"命令执行"

## 长期愿景

- [ ] 模板/分镜社区共建（PR 提交分镜实录，自动收录）
- [ ] 多语言 README（英文完整版）
- [ ] 实时预览（渲染即预览的本地 Web 服务）

## 设计原则（不随版本变化）

1. 本地优先：素材不上传，隐私安全
2. 确定性：固定随机种子，任意帧可复现
3. 版权红线：只学风格不搬素材
4. 渐进披露：主文档精简，细节按需加载
