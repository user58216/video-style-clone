# video-style-clone · 效仿视频创作

> **A TeleAgent Skill**: analyze a reference video's type, style and narrative, then programmatically render a **brand-new same-type video** frame by frame with Python — no uploads, fully local.
>
> 给我一段参考视频，我先"看懂"它的类型、风格、节奏和叙事结构，再用代码逐帧绘制一条同类型的新视频（MG 动画 / 概念广告 / 片头 / 启动动画）。全程本地处理，无需上传素材。

## ✨ 能做什么

- 复古点阵 / 线稿 / 几何风格的 **MG 动画、概念广告、片头、启动动画**
- 世界地标"AI 视觉识别"蒙太奇：扫描线绘制线稿 → 检测框锁定 → 地名/经纬度/置信度标签
- 数据洪流、数字雨、神经网络生长、粒子汇聚、轨道环终章等科幻动效
- 一键部署为软件启动画面（播放视频后无缝衔接真实软件窗口）

**不做的边界**：真人实拍、复杂 3D 渲染、AE 级特效镜头、剪辑混剪（需要原素材参与的视频）。

## 🚀 安装

把整个 `video-style-clone/` 文件夹放入 TeleAgent 桌面端的技能目录（或在客户端【技能】中导入），重启后即出现在技能列表：

```
video-style-clone/
├── SKILL.md                      # 技能主文件：六步工作流 + 红线
├── references/
│   ├── rendering.md              # 渲染骨架 / 9 类风格技法库 / 坑清单 / 分镜实录
│   └── boot-deploy.md            # 启动器部署：参数语义 / 时间轴换算 / 自检回滚
├── scripts/
│   └── analyze_reference.py      # 素材解析一条龙：ffprobe + 抽帧 + 拼图
├── 解释说明.md                    # 面向使用者的完整解释（含实战记录）
├── README.md
└── LICENSE
```

**环境要求**：Windows + Python 3（`numpy`、`Pillow`）+ ffmpeg。

## 💬 使用方法

对 TeleAgent 说：

> "效仿这个视频（拖入路径）做一个同类型的动画"
> "照着这条视频的风格，做一个 AI 主题的概念片"
> "把这条视频设为 TeleAgent 的启动画面"

技能会先与你确认 3 个决策点（主题内容 / 文案语言 / 配乐），然后全自动完成渲染与质检。

## 🔧 工作流

```
参考视频 ─► ①素材解析（抽帧+拼图+视觉分析） ─► ②需求确认
        ─► ③分镜设计 ─► ④逐帧渲染（Python+PIL，固定随机种子）
        ─► ⑤合成 H.264 + 双重抽帧质检 ─► ⑥交付
        ─► ⑦（可选）部署为启动动画（--self-test 自检）
```

## 🎨 技法亮点

| 技法 | 实现思路 |
|---|---|
| 点阵化 | 剪影网格采样 → 放大坐标画圆点 |
| 线稿扫描绘制 | 元素按 y 范围裁剪，扫描线从下往上显现 |
| AI 检测框+标签 | 四角 L 线收拢 + 地名打字机 + 经纬度 + 置信度滚动 |
| 数据洪流/数字雨 | 粒子向心插值 + "0/1" 字符列下落 |
| 神经网络球 | 斐波那契球面布点 + 绕轴投影 + 近邻连线 + 620 粒子汇聚 |
| 轨道环终章 | 椭圆弧前后分层遮挡 + 城市光点拖尾 |

所有随机数固定种子 —— 任意帧可复现、可单独重渲。
